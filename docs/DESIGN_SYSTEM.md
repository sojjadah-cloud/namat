# NAMAT Design System Documentation

## Brand Colors
* **Primary**: `#4F6B57` (Deep natural green) - Primary buttons, strong text accents, active navigation.
* **Secondary**: `#8DA78F` (Soft sage green) - Secondary actions, tags, progress visualization.
* **Background**: `#F6F8F4` (Warm off-white) - Dominant page background.
* **Surface**: `#E9E4D9` (Warm natural beige) - Cards, lifestyle sections, feature panels.
* **Accent**: `#D8B88C` (Warm earthy gold) - Premium features, rewards, badges.

## Typography
* **English**: Inter
* **Arabic**: IBM Plex Sans Arabic

## UI Components & Primitives
* **Radius System**:
  - Small: 8px
  - Medium: 12px
  - Standard: 16px
  - Large: 20px
  - XL: 24px
  - Hero/promo cards: 28–32px
* **Shadows & Depth**: Calm shadows, light depth. Avoid giant shadows.
* **Borders**: Thin borders.
* **Motion**: 150-250ms premium subtle UI transitions. Avoid excessive animation. Respect `prefers-reduced-motion`.

## Accessibility (a11y)
* High color contrast.
* Semantic HTML and keyboard navigation.
* Do not encode meaning solely through color.

## Visual Rules
* High-quality wellness/lifestyle photography.
* Clean line icons (Lucide React).
* Generous whitespace.
* Avoid neon colors, cartoon characters, and visually noisy backgrounds.

## Responsive Behavior
* Mobile (360px+), Tablet, Laptop, Desktop, Wide Desktop.
* Mobile-first mindset. Touch targets of appropriate size.
* Avoid desktop tables on mobile; use stacked rows or cards instead.
